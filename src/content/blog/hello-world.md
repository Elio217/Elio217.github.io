새로운 것을 배울 때마다 머릿속에 작은 별이 하나 생기는 것 같습니다. 금세 잊히는 발견도 있지만, 글로 남기면 나중에 다시 찾아갈 수 있는 좌표가 됩니다.

이곳은 그 좌표들을 하나씩 모아갈 **Elio의 개발 블로그**입니다.

## 무엇을 기록할까요?

거창한 주제보다는 직접 부딪히며 알게 된 것부터 남기려 합니다.

- 처음 접한 개념을 나만의 언어로 정리한 글
- 코드를 작성하다 만난 문제와 해결 과정
- 작은 프로젝트를 만들며 배운 점
- 다시 꺼내 보고 싶은 도구와 개발 습관

정답에 도착한 순간뿐 아니라, 왜 그런 답을 찾게 되었는지도 함께 적겠습니다.

## 이 블로그의 시작

이 공간은 [Astro](https://astro.build/)로 만들고 GitHub Pages에 올릴 수 있도록 구성했습니다. 글은 Markdown 파일로 관리합니다. 코드와 기록이 같은 저장소에 있으니, 글이 바뀌는 과정도 커밋으로 남길 수 있습니다.

```text
작은 궁금증 → 직접 해보기 → 이해하기 → 기록하기
```

도구를 완벽하게 다루는 것보다, 자주 돌아와 한 줄이라도 남기는 공간이 되었으면 합니다.

## 작게, 그리고 꾸준히
